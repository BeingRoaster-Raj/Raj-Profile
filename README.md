# Raj Anand | Portfolio

An interactive 3D portfolio. Particles change shape as you scroll (Three.js + bloom), the projects scroll sideways, and there's a hidden terminal (press ` on the site).

## Run locally
Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

## Deploy on GitHub Pages
1. Upload these files to the root of a repository (e.g. `BeingRoaster-Raj.github.io` or `portfolio`).
2. Go to **Settings → Pages**, set **Source** to `Deploy from a branch`, and pick branch `main` with the `/ (root)` folder.
3. After a minute the site is live at `https://beingroaster-raj.github.io/` (or `/portfolio/`).

## Files
- `index.html`: the whole site (HTML, CSS and JS)
- `Raj_Anand_Resume.pdf`: the file behind the Resume button
